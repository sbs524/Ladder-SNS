### 서버 환경 변수

다음 환경 변수 등록 완료. 비밀값은 Render에만 저장한다.

```text
NODE_ENV
APP_URL
VITE_SUPABASE_URL
VITE_SUPABASE_PUBLISHABLE_KEY
GEMINI_API_KEY
SUPABASE_SERVICE_ROLE_KEY
GOOGLE_YOUTUBE_CLIENT_ID
GOOGLE_YOUTUBE_CLIENT_SECRET
OAUTH_TOKEN_ENCRYPTION_KEY
OAUTH_STATE_SECRET
YOUTUBE_SYNC_WORKER_ENABLED
```

운영값:

```text
NODE_ENV=production
APP_URL=https://laddersns.com
YOUTUBE_SYNC_WORKER_ENABLED=true
```

## Google Auth Platform / Google Cloud

### 완료된 설정

- Supabase 일반 Google 로그인용 OAuth Client 설정 완료
- Supabase callback URI 등록 완료

```text
https://<supabase-project-ref>.supabase.co/auth/v1/callback
```

- YouTube Data API v3 활성화 완료
- YouTube Analytics API 활성화 완료
- YouTube 서버 연동용 OAuth Client 설정 완료
- YouTube OAuth callback URI 등록 완료

```text
https://laddersns.com/api/connections/youtube/callback
```

- YouTube 읽기·쓰기 권한 범위 설정 완료 (영상 수정·삭제, 댓글 답글·모더레이션을 위해 `youtube.readonly`에서 교체)
  - `https://www.googleapis.com/auth/youtube.force-ssl`
  - `https://www.googleapis.com/auth/yt-analytics.readonly`
  - 수익 기능을 사용할 경우 `https://www.googleapis.com/auth/yt-analytics-monetary.readonly`
  - `youtube.force-ssl`은 민감 범위라 Testing 모드에서는 등록된 테스트 사용자만 동의 가능. 이전에 `youtube.readonly`로만 연결된 채널은 재연결(재동의)해야 쓰기 기능이 활성화된다.

### 남은 이슈: Branding / Audience

일반 Google 로그인과 YouTube 전용 OAuth 설정에서 Google Auth Platform의 Branding 작업이 완료되지 않았다.

> Branding과 Audience는 OAuth Client별 값이 아니라 Google Cloud 프로젝트 단위 설정이다. 두 OAuth Client가 같은 프로젝트에 있으면 이 이슈도 공통으로 적용된다.

- Audience 화면에는 Testing 및 External 관련 상태가 표시됨
- Audience 또는 Branding 값을 수정하려 해도 변경할 수 없는 상태임
- 이 상태는 코드 문제가 아니라 Google Cloud 프로젝트의 OAuth 동의 화면/조직 정책/프로젝트 권한에 관한 콘솔 설정 이슈로 분리해 관리한다.

이 문제가 해결되기 전에는 OAuth 공개 배포와 외부 사용자 접근 정책을 다시 확인해야 한다. 내부 테스트 또는 등록된 테스트 사용자의 연결 가능 여부도 Google 콘솔에서 별도로 확인한다.

## 의도적으로 설정하지 않은 항목

- Supabase Storage 기반 프로필 이미지 업로드
- Supabase Realtime 또는 Redis 기반 다중 서버 댓글 fan-out
- Instagram, Threads, X OAuth 및 API 설정
- `app.laddersns.com`, `api.laddersns.com` 서브도메인 분리
- Google OAuth Production 게시 및 검증 완료

## 운영 원칙

- Secret, service role key, OAuth client secret, SMTP 비밀번호는 Git·문서·프론트 코드에 기록하지 않는다.
- `VITE_` 환경 변수에는 공개 가능한 값만 넣는다.
- YouTube OAuth용 Client ID/Secret과 Supabase service role key는 Render 서버에서만 사용한다.
- 외부 콘솔 설정이 바뀌면 이 문서의 상태와 확인일을 함께 갱신한다.
